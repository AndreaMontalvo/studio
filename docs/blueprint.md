# **App Name**: ChatForge

## Core Features:

- Chat Configuration: Admin panel to define chat parameters: application name, prompts (persistent, welcome, final, waiting message), message limits, character limits, animation speed, and language selector.
- Chat Execution: Initiate and run configured chats in a new window or tab based on the parameters set, including displaying a keyboard typing animation when showing the simulated response.
- Chat List Management: Dashboard to visualize and manage all created chats with options to edit, duplicate, delete, or manage existing chats.
- Chat Data Persistence: Save chat configurations as JSON files in a designated 'data' directory.
- Simulated Responses: Simulate chat responses from a predefined set of strings, without connecting to an external API.

## Style Guidelines:

- Primary color: A deep indigo (#4B0082) to convey professionalism and focus.
- Background color: Very light gray (#F0F0F0) provides a clean, modern backdrop.
- Accent color: A vibrant teal (#008080) will draw attention to important UI elements.
- Headline font: 'Poppins' (sans-serif) for a geometric and modern feel.
- Body font: 'PT Sans' (sans-serif) offers readability and approachability.
- Use minimalist, clear icons to represent chat functions and settings.
- Employ a card-based layout for chat list items to enhance organization and visual appeal.
- Use keyboard typing animation when displaying simulated response.
- Palette: Complementary violet and yellow colors for contrast and visual interest.
